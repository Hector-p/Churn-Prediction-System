Churn Prediction System (ML + FastAPI + Streamlit + Docker)
Overview

This project is a production-ready Machine Learning system that predicts customer churn and provides actionable insights through an interactive dashboard.

It combines:
Machine Learning models for prediction
A backend API for serving predictions
A frontend dashboard for visualization
Containerization for deployment
Features
Churn Prediction API
Interactive Dashboard
Real-time Predictions
Model Comparison & Tracking
Experiment Tracking with MLflow
Dockerized Architecture
Deployment-ready (Render)
